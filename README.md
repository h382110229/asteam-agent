# ASTeam Agent (v1.7.1)

> 企业级 Windows 桌面智能体客户端 · 基于 `deepseek-harness` 内核深度封装，集成企业私有扩展 Hub (安全验签与权限沙盒)、动态弹性子智能体集群 (Worker Pool 并发熔断与 Map-Reduce)、跨工程知识图谱与出境数据安全围栏、零遮挡并排分栏工作台、Swarm 动态泳道常驻看板、物理系统时钟纪律注入、后台定时长程自主巡检、官方 MCP 生态市场、项目架构规约体系、影子快照时光机与全模态原生驱动引擎。

---

## 🌟 核心特性总览

### 1. 📜 项目级行为准则与架构规约 (Project Rules · v1.4.0 新增)
- **智能嗅探项目规约**：自动感知项目根目录下的 `.asteamrules`、`.asteam/rules` 或 `ASTEAM.md`；
- **System Prompt 顶层注入**：在任何交互会话启动时，以最高优先级注入智能体底层思考上下文，严苛遵循团队编码规范（如 TypeScript 严格规范、前端禁 any、色彩规范等）；
- **内置三套企业级工程模版**：提供 TypeScript 严苛规范、全栈通用规范、Python 生产级工程规范，支持前端一键创建并落盘；
- **顶部规约状态勋章 (Rules Badge)**：实时显示当前生效的规约规则数与字符量，支持一键点击抽屉查阅。

### 2. 🎯 全能 `@` 上下文提及中心 (Unified Context Mention Hub · v1.4.0 新增)
- **多 Tab 上下文菜单**：聊天输入框键入 `@` 即可唤起半透明玻璃拟态上下文浮窗，支持【全部 / 文件 / Git 变更 / 技能】四合一无缝切换；
- **`@file` 文件模糊搜索与注入**：支持实时模糊搜索工作区代码文件，消息发送时以标准 Markdown 代码块无损挂载到 Prompt 附加上下文中；
- **`@git-diff` 未提交变更捕获**：一键捕获当前工作区所有暂存与未暂存的 Git 修改，无需手动复制 diff 内容即可向 Agent 发起审查与调试；
- **`@skill` 技能快捷引用**：无缝挑选并组合已安装的工程与分析技能。

### 3. ⏪ 影子快照与时光机一键回滚 (Checkpoint & Timeline · v1.4.0 新增)
- **修改前自动捕获快照**：Agent 在执行文件创建或写入修改前，底层自动捕获被改动文件的影子版本；
- **聊天流【⏪ 撤销本轮修改】**：每次执行完成后提供一键撤销按钮，1 秒钟平滑回滚至修改前状态；
- **工作台【时光机 (Timeline)】抽屉**：可视化历史快照列表，展示生成时间、变更文件数量与代码增删指标，支持任意历史快照点一键还原，并联动更新 Git 状态。

### 4. 🎨 LLMAPI Auto 全模态多模型驱动引擎 (Full-Modal Suite · v1.4.0 新增)
- **`Auto` 模型全场景自动智能路由**：接入点配置为 `Auto` 时，智能体根据任务性质自动路由底层最优专长模型；
- **全模态工具矩阵全面集成**：
  - 🖼️ `generate_image`：文生图/设计稿渲染，自动路由 `agnes-image-2.1-flash`，高清图片即刻本地落盘；
  - 🎬 `generate_video`：文本生视频与动态画面渲染，自动路由 `agnes-video-2.5-flash`，异步任务与直链自动抓取；
  - 🧠 `generate_embedding`：文本向量提取，自动路由 `gemini-embedding-2`，返回 3072 维高精向量；
  - 🎙️ `text_to_speech` & `audio_to_text`：语音合成与识别工具接入，内置优雅诊断兜底；
- **33 款在线模型强类型支持与能力矩阵推导**：覆盖 Chat、Embedding、Image、Video、ASR 等全部 9 维能力体系；
- **原生富媒体播放与预览工作台**：聊天气泡与工作台抽屉内置原生视频播放器与音频播放器，支持全屏预览与外部文件定位。

### 5. 📁 数据与存储中枢 (Storage & Data Hub · v1.3.0)
- **彻底脱离系统 C 盘占用**：支持用户将存储根目录自定义绑定到任意大容量磁盘（如 `D:\ASTeamData\`），杜绝系统盘爆满与路径冲突；
- **五大标准子目录自动维护**：
  - `workspaces/`：通用免项目工作区默认主目录；
  - `skills/`：全局技能存放仓库；
  - `memory/`：全局用户画像与跨项目通用避坑库；
  - `artifacts/`：生成的大屏、图表与文档存档；
  - `logs/`：调度诊断与交互终端日志；
- **Windows 原生目录选择器与平滑搬家向导**：设置中心支持一键调出 Windows 文件夹选择器，自动扫描历史旧目录（`~/.asteam`）并提供向导式一键平滑搬迁。

### 2. 🧠 长期记忆与知识沉淀体系 (Memory Bank · v1.3.0 新增)
- **双层持久化记忆架构**：
  - **项目级专属记忆 (`.asteam/memory/MEMORY.md`)**：随项目代码版本库流转，记录技术选型、前端规约（如 TypeScript 严格类型、禁止 any、主题色等）；
  - **全局通用画像 (`memory/user_profile.md` & `GLOBAL_MEMORY.md`)**：跨项目常驻记录用户的编程风格与避坑经验；
- **显式快捷指令 `/remember` 与 `/learn`**：
  - 在聊天框直接输入 `/remember 本项目统一使用 Tailwind CSS 规约`，前端毫秒级直接落盘写入，无需消耗 LLM Token；
- **会话启动自动感知常驻注入**：内核初始化时自动拼装记忆上下文注入 `systemPrompt`，模型在第一轮交互中即自主遵循工程约定；
- **Agent 自主反思沉淀 (`remember_fact` 工具)**：智能体在长任务执行遇到踩坑点时，可自主调用工具将经验固化到记忆库中。

### 3. 🛡️ 多 LLM 供应商容灾池与 524 自动重试 (Multi-Provider Fallback · v1.3.0 新增)
- **主备候选优先级队列**：在【AI 模型与供应商】设置中支持配置多条备用线路（内置硅基流动、DeepSeek 官方、本地 Ollama 预设），各线路独立支持 API Key 与连通性测试；
- **平滑无感故障转移 (Failover Retry)**：
  - 当主线路触发 **Cloudflare 524 超时**、**429 限流** 或 **500/502/503 节点异常** 时；
  - 在思考推理流（Thought Stream）中即时给出安全警示，并在毫秒级无感切入备用线路发起重试，保障长链路编码与执行永不断线！

### 4. 👁️ 模型特异性能力识别与多模态自适应路由 (Model Capability Routing · v1.3.0 新增)
- **强类型能力标签体系**：精准识别 `['text', 'vision', 'reasoning', 'tools', 'image_gen']`，推导识别慢思考 R1 模型、GPT-4o/Claude-3/Gemini/Mimo 多模态模型与专用生图模型；
- **图片附件智能防崩溃路由**：检测到对话包含图片时，自动过滤跳过不支持 Vision 的纯文本线路，优先命中具备视觉能力的服务商，避免上游 400 Bad Request；
- **可视化能力标签与前端防御**：主模型及备用卡片均展示直观徽章，拖入图片且当前主模型为纯文本时，聊天框上方即刻弹出防御性提醒并支持快捷切换。

### 5. ⚡ 实时交互式控制台与任务流看板 (Live Terminal & Task Stream)
- **实时流式终端输出**：当 Agent 执行终端诊断或测试构建命令时，前端步骤卡片实时流式打印 ANSI 彩色终端输出；
- **双向实时 Stdin 交互桥接**：遇到需要用户确认（如 `[y/N]` 或环境初始化选项）的命令时，自动唤起前端输入桥接，用户敲入字符即刻注入终端子进程 stdin；
- **Windows 原生 PowerShell UTF-8 编码兜底**：自动注入标准 UTF-8 BOM 头，彻底杜绝 Windows PowerShell 终端与脚本中文乱码。

### 2. 🖥️ 原生多模态产物实时预览与工作台 (Live Artifacts & Workbench)
- **多模态所见即所得渲染**：
  - **HTML 交互大屏/微应用**：支持 Tailwind CSS、ECharts、交互式脚本安全沙箱运行；
  - **Mermaid 架构流程拓扑图**：动态自适应缩放与高清矢量渲染，内置语法纠错与引号容错；
  - **SVG 矢量设计图**：支持代码检视、棋盘格背景切换，内置 XML 实体转义与 DOM 序列化容错；
- **左右双分栏自由拉伸与记忆 (Draggable Splitter)**：
  - 右侧工作台抽屉左边缘支持自由鼠标拖拽拉伸（460px ~ 屏幕宽度-240px），带防 iframe 拖拽断触全局遮罩；
  - 双击拖拽把手极速复位至黄金比例（55% 屏宽），宽度自动持久化至本地存储；
- **独立系统子窗口弹出 (Pop-out Window for Multi-Screen)**：
  - 工具栏一键弹出独立系统子窗口，将复杂大屏或架构图脱离主窗口拖曳至副显示屏全屏常驻比对；
- **多设备视口一键自适应**：支持【桌面端全宽】、【平板 768px】、【移动端 390px】即时模拟切换；
- **交付制品智能置底呈现**：将【交付制品已就绪 · 打开实时预览】卡片固定在所有分析结论的最下方，避免长篇大论中回翻。

### 3. 💾 交付制品一键导出与系统剪贴板原生复制 (Export & Native Clipboard)
- **HTML 交付物**：一键另存为独立自包含 `.html` 文件，随时离线双击在浏览器中演示；

  - 支持直接在微信、Word、PPT 或飞书中按下 `Ctrl + V` 原图粘贴；
- **SVG 源码文件下载**：保留合规 XML 命名空间与实体定义的矢量源文件导出。

### 4. 🎯 `@` 键快捷唤出已安装技能 (@ Skill Mention)
- **前端自动补全浮窗**：在聊天输入框键入 `@` 或 `@关键词`，即刻弹出半透明玻璃拟态的技能下拉菜单；
- **丰富元数据呈现**：展示技能名称、ID、类别徽章（`[内置]` / `[自定义]` / `[项目]`）与功能摘要；

### 5. 🌊 LLMAPI 完整流式响应传输 (Stream Mode & Reasoning Stream)
- **流式响应模式 (Stream Mode) 可配置化**：
  - 在【设置 -> AI 模型与供应商】中提供专属开关，**默认开启（推荐）**，并附带防 524 超时说明；
  - 允许特殊内网自建网关用户手动关闭；连通性测试自动同步携带流式握手；
- **SSE 流式传输与慢思考深度推理链实时消费**：
  - 底层调用向网关发送 `stream: true`；
  - 升级 SSE 解析器，支持同时消费 `delta.content`（正文）与 `delta.reasoning_content` / `delta.thought`（思考推理链）；
  - 即使在模型长链思考或高并发排队阶段，亦保持每秒有数据包流动，有效防止 Cloudflare 100 秒 idle timeout 导致的 HTTP 524 异常；
  - **思考提拔机制 (Thought-to-Content Auto Promotion)**：若网关将生成正文全部作为思考链返回，任务完成时自动将思考内容提拔为正文，确保消息结论与产物卡片正常展示。

### 6. 📌 全周期任务执行置顶动态看板 (Persistent Progress HUD)

- **执行态与完成态全周期常驻**：任务完成后依然保持展示 `✅ deepseek-harness 规划与执行已就绪 (4/4 步骤完成)`；
- **就地一键检视步骤详情**：在置顶看板右侧点击【检视步骤】，即可在顶部原地下拉出所有规划步骤、调用工具与输出摘要的完整清单。

## 🛠️ 技术架构

- **宿主运行时**：Electron 34 + Node.js 22
- **网络通信引擎**：Chromium 原生 `net.fetch`（全面支持 Windows 系统网络代理、IPv6 Happy Eyeballs 并发选路与极速 SSE 流式传输，握手 <1s）
- **渲染层**：React 18 + TypeScript + Vite 6 + Tailwind CSS 4（严格启用 `tsc --noEmit` 编译安全门禁）
- **图标系统**：Lucide React
- **多模态预览**：Mermaid.js 10 + KaTeX + 沙箱化 iFrame
