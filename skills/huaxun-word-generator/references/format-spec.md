# 华讯 Word 格式规范（摘自 v2.3-20240119 模板）

## 版面

- 纸张：A4 竖版（默认）；宽表/大拓扑图可用横版分节，插回后需检查页眉页脚分页。
- 页脚：`<文档标题>  上海华讯网络系统有限公司  页码` 居中。
- 封面：左上 ECCOM 华讯 logo（客户 logo 可替换），中部文档标题居中加粗，下方版本/日期/项目/客户。
- 目录：Title「目录」+ TOC 域（1–3 级），Word 中更新域。
- 版本控制信息：Title +「文档属性」表 +「文档变更过程」表。

## 字体与字号

| 元素 | 字体 | 字号 | 备注 |
|------|------|------|------|
| 正文 Normal | 等线/宋体（eastAsia） | 12pt | 两端对齐，首行缩进 2 字符 |
| Heading 1 | 黑体 加粗 | 15pt | 编号「第N章」 |
| Heading 2 | 黑体 加粗 | 14pt | 编号 N.N |
| Heading 3 | 黑体 加粗 | 约 12–13pt | 编号 N.N.N |
| Heading 4 | 黑体 加粗 | 约 12pt | 编号 N.N.N.N |
| 表格正文 | 等线 | 10.5pt | 单倍/1.15 行距 |
| 封面标题 | 黑体 加粗 | 18pt 居中 | |
| 封面信息 | 宋体 | 14pt | |

## 编号

- 一级：`第%1章`
- 二级：`%1.%2`
- 三级：`%1.%2.%3`
- 四级：`%1.%2.%3.%4`

生成脚本默认**预编号**写入标题文本，保证 LibreOffice 导出 PDF 时页码/目录一致；Word 内仍可更新 TOC 域。

## 表格对齐（相对原模板的修复）

原模板「插入表格」示例中表头居中、数据单元格对齐不一致（`align=None` / 左对齐混用）。本 skill **强制**：

1. **表头行**：水平居中 + 轻底色 + 加粗。
2. **数据单元格**：默认**左对齐**；短字段列（序号/版本/日期/更新人/作者/审核人/属性等）**居中**。
3. **所有单元格**：**垂直居中**；边距收紧；**清除首行缩进**。
4. **按内容动态定列宽**（固定布局 + gridCol），长文本换行。

## 表格完整度（防割裂，skill 级规则）

生成器**永远**执行以下规则，不依赖单次 demo 修补：

1. **紧跟在数据表后的 `note`（注释/建议/小心/警告）必须并入同一张表**，作为最后一行（首列标签，其余列合并放说明），**禁止**拆成第二张表。
2. 表格之间**不允许**夹空段落/空行；后处理会合并「表 + 空段 + 注释表」。
3. 表内所有行加 `cantSplit`；题注 `keepNext`，避免题注与表拆页。
4. 行数（含表头与注释行）≥5 时整表另起一页；或 content JSON 中 `page_break: true`。

content 写法（推荐把注声明写在表上，或紧随其后的 note 块）：

```json
{"type": "table", "caption": "表1 …", "header": [...], "rows": [...],
 "note": {"kind": "注释", "text": "…"}}
```

或：

```json
{"type": "table", ...},
{"type": "note", "kind": "注释", "text": "…", "merge": true}
```

`merge: false` 时才单独成表。

## 标准内容块

| 块类型 | 说明 |
|--------|------|
| para | 正文段落，两端对齐 + 首行缩进 |
| h2/h3/h4 | 节内小标题 |
| bullets / numbers | 项目符号 / 序列清单 |
| table | 带 caption 的数据表（自动对齐） |
| note | kind=注释/建议/小心/警告 |
| config | 设备配置粘贴区（单格表） |
| signature | 签字盖章块 |
| image | 插图 + 可选图注 |
| page_break | 分页 |

## 交付

- 内部编辑稿：`.docx`
- 对外交付：`.pdf`（经 LibreOffice `--convert-to pdf`）
- 交付前建议：更新目录域、检查表格跨页、确认无 `{{占位符}}` 残留。
