# 华讯 Excel 格式规范（摘自 Excel模板（暂定））

## 工作簿结构

标准交付表固定包含：

| 工作表 | 作用 | 方向 |
|--------|------|------|
| 版本控制 | 文档属性 + 版本变更记录 | 横向 |
| 关于 | 横幅标题、用途、目录索引、保密声明、联系方式 | 纵向 |
| 数据表 ×N | 业务数据（通讯录/设备/IP/检查表等） | 纵向 |

`关于` 页的 sheet 索引必须与实际工作表名一致。

## 颜色与字体令牌

| 令牌 | 取值 | 用途 |
|------|------|------|
| FONT | 微软雅黑 | 全簿默认 |
| SIZE | 10 | 全簿默认 |
| HEADER_FILL | `#FF008080` | 表头/分区标题/横幅底色（ARGB，视觉 `#008080`） |
| HEADER_FG | `#FFFFFF` | 表头文字（加粗） |
| DATA_FG | `#404040` | 数据单元格文字 |
| PLACEHOLDER_FG | `#FF0000` | 版本控制中的待填占位符 |
| BORDER | thin `#A6A6A6` | 数据区边框 |
| BORDER_HEADER | thin `#FFFFFF` | 表头边框（与底色融合） |

## 版本控制页

布局（横向 A4）：

```
B2:E2  合并标题「文档属性」  青绿底 + 白字加粗居中
B3     「属性」 | C3:E3 「内容」  表头行
B4–B9  项目名称 / 文档标题 / 文档版本号 / 版本日期 / 作者 / 审核人
C4:C9  内容值（C:E 合并），已填值用 DATA_FG，占位符用 PLACEHOLDER_FG
（空行 10–11）
B12:E12 合并标题「版本控制」
B13–E13 表头：版本 | 更新日期 | 更新人 | 主要更新内容
B14–E17 变更记录（预留 4 行，可扩展）
```

列宽：A≈4.7，B≈11，C≈16，D≈17，E≈38。

打印：页眉=文档标题，页脚=页码。

## 关于页

布局（纵向）。**A1:J1 横幅必须保留**（禁止删除/取消合并）：

```
A1:J1  青绿横幅：文档标题，白字加粗，高度 24，整行合并
A2    「关于这份表格: 」加粗
A3    目的说明（按内容增高行高）
A5    「随着项目的进展，该表格会根据实际情况不断更新」
A7    「这里你可以找到:」加粗
A8…   各数据表名称（与实际 sheet 名一致）
（空一行）
      「如何使用这张表:」+ 使用说明
（空两行）
      「关于信息的保密:」+ 保密声明
（空两行）
      「如果有任何建议或反馈信息，请联系：」
      维护人 / 邮箱 / 电话（未填则红色占位）
      「最近更新 <yy年mm月dd日>」
```

列宽：A≈110（长句尽量单行），B–J≈8（支撑横幅合并宽度）。

打印：页眉=文档标题，页脚=页码。视图必须 `normal`。

## 数据表页

| 项 | 规范 |
|----|------|
| 起始位置 | 默认表头在 `B2`；标题条在 `B1` |
| 标题条 | 表头上一行：表名，HEADER_FILL + 白字，合并至表宽，高 22 |
| 表头行 | `start_row`，HEADER_FILL + 白字加粗，水平/垂直居中 |
| 数据区 | 自 `start_row+1`；短列居中、长列左对齐；四边 thin 边框 |
| 行高 | 标题 22 / 表头 20 / 数据 16.5（长文本换行按行数增高） |
| 冻结 | 表头下一行（如 `B3`）；**selection 必须 bottomRight + activeCell=B3** |
| 视图 | 强制 `normal`（禁止 `pageLayout`） |
| 网格线 | 默认关闭 |
| 纸张 | A4 纵向 |
| 空行预留 | 至少约 20 行，便于人工续填 |

### 对齐（短字段居中）

序号、版本、日期、更新人、作者、审核人、状态、优先级、角色、类型、类别、编号、姓名、数量、是否通过、严重级别等 **居中**。  
名称、描述、说明、备注、取值、内容、主要更新内容等 **左对齐**。

### 列宽与换行

| 列类型 | 宽度策略 | wrap |
|--------|----------|------|
| 序号/边距 | 6–8 | 否 |
| 姓名/角色/状态 | 按内容约 9–14 | 否 |
| 手机 | **最小 15** | **否** |
| 邮箱 | **最小 30** | **否** |
| 管理IP/起止IP/网关 | **最小 15** | **否** |
| 日期类 | 最小 13 | 否 |
| 备注/说明/描述 | 最小 16，最大约 48 | **是** |

原则：**能加宽就单行**；只有自由文本列才换行。禁止邮箱/手机被截断。

## 预设表类型（`type`）

| type | 默认表头 |
|------|----------|
| contact | 序号, 姓名, 角色, 单位/部门, 手机, 邮箱, 备注 |
| device | 序号, 设备名称, 型号, 管理IP, 位置, 责任人, 备注 |
| ip_plan | 序号, 网段/用途, 网关, 起始IP, 结束IP, 掩码/长度, 备注 |
| checklist | 序号, 检查项, 检查方法, 期望结果, 实际结果, 是否通过, 备注 |
| issues | 序号, 问题描述, 严重级别, 责任人, 状态, 计划关闭日, 备注 |
| schedule | 序号, 任务名称, 负责人, 开始日期, 结束日期, 状态, 备注 |
| inventory | 序号, 资产编号, 资产名称, 规格型号, 数量, 存放位置, 备注 |
| param | 序号, 参数名, 参数值, 有效范围, 生效方式, 备注 |
| matrix | 必须提供 `header` |

## 交付与 QA

1. 产出单文件 `.xlsx`；PDF 仅用户明确要求时导出。
2. 打开无修复提示；工作表名与 `关于` 索引一致。
3. 无 `{{` / `TODO` / `TBD` 残留；版本控制占位已填实。
4. 全部 `sheet_view.view == normal`；数据表 freeze=B3 且 selection=bottomRight。
5. 「关于」A1:J1 横幅完整；手机/邮箱列单行可读。
6. 表头青绿、边框完整、短列居中、长列左对齐。
